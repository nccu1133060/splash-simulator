# 速度估計模型 [C] 與回推比較：設計文件

狀態：**草稿，待使用者核可**（2026-11-18）
上游：`飛濺溯源專題統整.pdf` 第十一節（[A]–[E] 流程、三方法比較）；`技術路徑選項分析.pdf` 決策 1、3、4、5、6
前置：`2026-10-21-simulator-design.md`；資料集 `datasets/expanded_public_trial_2500_20261111-105236/`

## 1. 目的與理由

專題核心是 [C]：從單滴水漬的形狀估計撞擊速度，再交給 [D] 含重力的軌跡回推。
本設計建立 [C] 的訓練與評估流程，並在模擬場景上做上游規定的三方法比較，回答 RQ3 的「模擬版」。

| 階段 | 內容 | 回答的問題 |
|---|---|---|
| 一：速度模型 | 從影像量特徵 → 物理公式基準線與 XGBoost 模型 → 誤差與不確定度 | AI 估速度能多準？斜向是否比前人公式好？ |
| 二：回推比較 | 每滴回推軌跡 → 多滴交會求源頭 → ① 直線法 ② 真實速度 ③ AI 速度 | 估出來的速度能不能讓源頭（尤其高度 Z）更準？ |

### 1.1 必須誠實面對的一點

在模擬資料裡，寬度 W 幾乎完全由法向速度決定（Laan 2014 公式、固定 3 mm 滴徑），長度 L = W / sin α。
所以**反解公式在模擬資料上本來就會很準**，AI 在模擬上的好成績不能證明它在真實照片上有用（設計文件反目標 1）。

因此本輪的價值是：
1. 建好「從影像量特徵 → 估速度 → 回推」整條可重跑的流程，實拍資料進來時直接套用。
2. 用**規則擾動測試**（第 4.4 節）測量模型對「形狀規則不準」有多敏感，作為模擬與現實落差的代理指標。
3. 模擬成績與日後實拍成績分開報告。

## 2. 目標、非目標、反目標

**目標**
- 特徵只從影像與遮罩量測，**不讀取答案欄位**（`width_mm`、`spine_count`、`weber` 等）。
- 速度輸出數值（m/s）＋不確定度區間（決策 4C：內部數值，對外可轉分級）。
- 同一設定與種子可重現：切分、模型、評估數字相同。
- 評估結果分「垂直（α ≥ 75°）／斜向」兩組報告（上游子實驗要求）。

**非目標**
- 分割模型 [A]（YOLO）：本輪直接使用模擬器的實例遮罩，隔離 [C] 本身的誤差。
- CNN 影像迴歸（決策 3C 備援）：留待之後，需要時可用外部顯示卡。
- 尾巴方向判斷（180° 模糊）：本輪用答案決定方向正負號，三種方法一律相同處理，比較仍公平；列為剩餘限制。
- 實拍資料、CFD（另見 `2026-11-18-validation-design.md`）。

**反目標**
- 模型輸入含任何答案欄位（資料洩漏）。特徵表可同時保存答案欄（供目標值、分組與比較），但送進模型的欄位必須通過白名單檢查。
- 同一場景的液滴同時出現在訓練與測試。
- 只報告模擬成績就宣稱模型可用於真實照片。

## 3. 系統結構

```
資料集（場景圖、實例遮罩、衛星遮罩、答案 JSON）
   │
   ▼
[特徵量測] 每滴：裁出該滴遮罩 → measure_stain（擴充）→ 特徵表 features.csv
   │                              （答案只取「目標值」與「分組用」欄位）
   ├──► [基準線 B0] arcsin(W/L) 求 α；W/d 求攤開係數 → 反解 Laan 2014 → 法向速度 → v = v_n / sin α
   ├──► [主模型] XGBoost 分位數迴歸（10%、50%、90%）
   ▼
[評估] MAE、相對誤差、區間涵蓋率；垂直／斜向；獨立測試集；規則擾動測試
   │
   ▼
[階段二 回推] 撞擊點＋方向 γ＋撞擊角 α＋速度 → 撞擊速度向量
   → 飛行模組 propagate 往回積分得軌跡 → 多滴最小平方交會 → (X0, Y0, Z0) 與答案比對
```

### 3.1 程式位置

- 同一個倉庫新增套件 `src/splash_model/`，沿用 `splash_sim` 的飛行模組、特徵量測與設定檔讀取。
- 訓練相依（`xgboost`、`pandas`）放在 `pyproject.toml` 的選用群組 `train`，只產資料的組員不必安裝。
- 指令：`splash-model features`、`splash-model fit`、`splash-model evaluate`、`splash-model backtrack`。
- 輸出到 `runs/<名稱>_<時間>/`（加入 `.gitignore`）：模型檔、切分清單、`metrics.json`、`report.md`、誤差圖。

備援方案：另開獨立倉庫。優點是相依完全分開；缺點是飛行模組與特徵量測要複製或發佈套件，兩邊容易不同步。推薦同倉庫。

## 4. 階段一：速度模型

### 4.1 特徵（全部由遮罩量測）

| 特徵 | 來源 |
|---|---|
| 面積、寬 W、長 L、W/L、毛刺數 | 既有 `measure_stain` |
| 周長、凸包實心度、邊緣粗糙度（周長／橢圓周長） | 擴充 `measure_stain`（設計文件 5.8 已列邊緣粗糙度） |
| 衛星小滴數、總面積、離主體最遠距離 | 從衛星遮罩量測 |
| arcsin(W/L) 換算的撞擊角 | 決策 5A |

另有不送進速度模型、只供回推使用的**量測觀察值**：方向角（[0, 180)）與水漬重心座標（mm）。方向角與速度大小無關（旋轉不變），所以不當特徵。

遮罩取得：由場景實例遮罩依 `instance_id` 取出該滴。排除規則直接讀答案的 `truncated` 標記與遮罩是否為空，新舊資料集共用同一流程（不依賴 `candidate_index.csv`）。

### 4.2 模型

- **B0 物理基準線**：已知滴徑 d = 3 mm（決策 6A），由 W 求攤開係數 ξ = W/d，對 Laan 2014 內插式數值反解得法向 We，再換算 v_n 與 v = v_n / sin α。
- **B1 常數基準線**：一律猜訓練集平均速度，用來看任何方法是否真的有學到東西。
- **主模型**：XGBoost，分別訓練 10%、50%、90% 分位數；中位數當點估計，10–90% 當 80% 不確定度區間。
- 超參數在驗證集上做小範圍格點搜尋；固定隨機種子。

### 4.3 資料切分

| 集合 | 來源 | 用途 |
|---|---|---|
| 訓練 | 現有資料集約 70% 場景 | 學習 |
| 驗證 | 現有資料集約 15% 場景 | 調超參數 |
| 內部測試 | 現有資料集約 15% 場景 | 第一次成績 |
| 獨立測試 | 用**新種子**、同一暫定設定新產 30 張場景 | 主要報告成績 |
| 規則擾動測試 | 同暫定設定，但 `spread_a` 1.24→1.05（攤開變大）、`angle_bias_deg` 0→+3°（Joris 2017 偏差方向）、毛刺參數回到 `default.yaml` 原值；新種子產 30 張場景。擾動幅度為 Claude 判斷 | 規則不準時模型退化多少 |

切分以場景編號為單位，清單寫入輸出資料夾。

### 4.4 評估指標

- 速度：MAE（m/s）、中位相對誤差、80% 區間實際涵蓋率（應接近 80%）。
- 分組：垂直 vs 斜向；速度三分段。
- 比較：主模型 vs B0 vs B1，在每個測試集上並列。
- 規則擾動：主模型與 B0 在擾動測試集上的誤差增幅。增幅大代表模型依賴規則細節，實拍時風險高。

## 5. 階段二：回推比較

- 每滴撞擊速度向量：水平方向取 γ（正負號用答案，見非目標），俯角取 α，大小依方法而定：
  - ① 直線法：不需速度，沿 (γ, α) 畫直線，最小平方求最近點（Joris 2015）。
  - ② 真實速度：用答案速度大小。
  - ③ AI 速度：用主模型中位數；交會時以區間寬度的倒數加權（上游 [E]）。
- ②③ 以飛行模組 `propagate` 往回積分取得軌跡曲線，求一個點使各軌跡的最近距離平方和最小（含阻力，對應決策 1C；同時報告只含重力的版本 1B）。
- 指標：每場景 XY 誤差、Z 誤差（mm），報告中位數與分布；在獨立測試集上計算。
- 判讀依上游：③ 明顯優於 ① → 創新在模擬上成立；③ 越接近 ② → 速度估計越好；③ 未優於 ① 也是有效結論。

## 6. 驗收標準

1. **無洩漏**：特徵表欄位以白名單檢查，測試會在加入任一答案欄位時失敗。
2. **切分正確**：任一場景只出現在一個集合，有測試保護。
3. **基準線正確**：對模擬器在關閉干擾時產生的單滴，B0 反解速度與答案相對誤差 < 5%（已知答案校準）。
4. **回推正確**：方法 ② 用答案的撞擊點、方向與速度時，源頭誤差 < 1 mm（驗證回推與交會程式本身）。
5. **可重現**：同設定執行兩次，`metrics.json` 相同。
6. **報告**：`report.md` 含 4.4 與第 5 節全部指標、垂直／斜向分組、規則擾動結果與 1.1 節的限制說明。
7. **效能**：在一般筆電上，從特徵量測到評估完成 < 10 分鐘（不需 GPU）。

## 7. 已知風險

| 風險 | 應對 |
|---|---|
| 模擬上成績虛高（1.1 節） | 規則擾動測試；模擬與實拍分開報告 |
| 固定 3 mm 滴徑使模型只適用固定滴管 | 依決策 6A 屬預期範圍；放寬時改產隨機滴徑資料並加入滴徑估計 |
| 交會求解在液滴少或方向接近平行時不穩 | 記錄條件數，不穩的場景單獨標記 |
| 180° 方向用答案決定 | 報告列為限制；之後加尾巴方向判斷 |
| 量測特徵在重疊液滴上失真 | 沿用候選清單；另外報告「含部分重疊」子集 |
